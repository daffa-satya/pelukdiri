# PELUKDIRI
### (Perangkat Lunak Kesejahteraan Digital Remaja Indonesia)

## Deskripsi dan Tujuan

Aplikasi ini dibuat untuk menurunkan screen time pada aplikasi hiburan seperti sosial media secara adaptif. Tujuan nya untuk meneliti kebiasaan para remaja indonesia yang sangat kompulsif dalam bermain media sosial. Hasil dari laporan aplikasi ini akan dimasukkan ke dalam laporan penelitian untuk memenuhi syarat-syarat OPSI (Olimpiade Penelitian Siswa Indonesia).

## Tutorial untuk Menginstall Aplikasi PELUKDIRI

1. Download apk dari [https://github.com/daffa-satya/pelukdiri/](https://github.com/daffa-satya/pelukdiri/)
2. Buka Play Store => Profile => Play Protect => icon gear di kanan atas => matiin scan apps with Play Protect. PELUKDIRI butuh akses aksessibilitas yang cuma dikasih ke aplikasi yang udah bersertifikasi, masalahnya sertifikasinya $25 dan lama sedangkan penelitian dikejar deadline
3. Install apk seperti biasa
4. Buka app info (Settings => Apps => PELUKDIRI => Allow restricted settings). Ini juga untuk masalah aksessibilitas
5. Di "Other permission" pastikan "Open new window while running on background" menyala
6. Buka aplikasi dan ikuti petunjuk, pastikan memberikan izin aksessibilitas, usage access, dan notifikasi
7. Pencet tarik data, sinkron sekarang, hitung ulang batas adaptif, jika grafik tidak terupdate pencet progress/pengaturan dan kembali ke beranda

**Note:**
- Aksessibilitas berfungsi buat ngecek kapan anda scrolling

## Cara Kerja Aplikasi

1. Mengambil data screen time yang kamu lakukan selama 7-14 hari ke belakang
2. Data yang sudah diambil tersebut akan dihitung dan dianalisa untuk melihat nilai tengah (mirip rata-rata) screen time yang telah dihabiskan user selama 7-14 hari ke belakang
3. Hasil dari analisa tersebut akan diimplementasikan dalam bentuk soal matematika dan pola agar user tidak melebihi screen time yang telah ditentukan melalui analisa
4. Semua data-data yang dikumpulkan akan dijadikan data penelitian untuk melihat seberapa efektif dan sering nya user dalam menggunakan aplikasi
